# Job-App-Tracker.
A simple web application to track and manage your job applications.

## Features.
- Add new job applications(company,position,status).
- View all saved application.
- Delete applications.
- Store data in the browser using *local storage*.
- Filter applications by status(company,position,status)
- Responsive design for mobile and desktop.

## Pages.
1. **index.html** - View all job applications.
2. **add.html** - Add a new job application.
3. **about.html** - Project pverview and features.
